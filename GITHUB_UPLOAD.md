## Upload steps

1. Sign in to GitHub and select **New repository**.
2. Enter the repository name above.
3. Paste the short description.
4. Select **Public**.
5. Do not add another README, licence or gitignore because they are already included.
6. Select **Create repository**.
7. Select **uploading an existing file**.
8. Open the extracted project folder and upload its complete contents, including the `.github` directory if your file browser displays it.
9. Enter the first commit message above and select **Commit changes**.
10. Add the suggested topics from the repository settings area.
