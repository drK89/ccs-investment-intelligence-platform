# Project Brief

## Business problem

Early-stage CCS portfolios often include several opportunities with different maturity, infrastructure, commercial and delivery characteristics. Decision-makers need a transparent way to compare scenarios, inspect assumptions and understand how changing priorities affects the result.

## Project objective

Build a public portfolio application that:

- validates a structured CCS opportunity dataset;
- ranks demonstration scenarios using configurable priorities;
- explains every score;
- tests ranking sensitivity and uncertainty;
- stores reproducible analytical runs; and
- exposes results through a dashboard, API and downloadable files.

## Users

- energy strategy analysts;
- portfolio and business-development teams;
- data analysts demonstrating explainable decision support;
- students and early-career professionals learning responsible analytics.

## Success criteria

1. Invalid data is rejected with a clear error.
2. Weights always normalize to 100%.
3. Every score can be decomposed into criterion contributions.
4. Ranking stability can be tested across alternative priorities.
5. Results are reproducible and exportable.
6. The repository contains no confidential or proprietary information.
